bitdispatcher VERSION

bitdispatcher is a free, open-source (Apache-2.0) computer-aided dispatch system for 911 centres. This installs it on this Mac as a service that:

  • starts when the Mac starts, before anyone signs in, and restarts if it stops;
  • serves the consoles over HTTPS on port 8443 (or the next free port from 9443);
  • keeps its records in a folder only its own service account can open;
  • keeps the Mac awake while it runs, so it can answer at any time.

The first administrator's password is shown once, at the end. An upgrade keeps the records, the settings and the users.

Needs macOS 12 or later, on Apple silicon or Intel. Not certified for any purpose; see the manual's chapter on what has and has not been tested.
