The rules it is built to

  • The dispatcher decides. Recommendations, advisory checks and agency scripts advise; nothing dispatches, closes or changes the priority of an incident on its own.
  • Every part of the screen shows something the dispatcher acts on. No decoration, no empty space.
  • Everything from the browser. A setting reachable only from a file or the command line is a bug.
  • A record that cannot quietly change. Every event is appended to a hash-chained ledger, and the live state is rebuilt from it in the tests to prove they agree.
