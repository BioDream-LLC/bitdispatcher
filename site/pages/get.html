Get it

Try it in your browser, or build it yourself

There is no release yet: bitdispatcher is built and tested, not yet in service. Try the live demonstration, or build it from source with Go and run it on your own computer.

The live demonstration

ICON:play Open the demo

Press Sign in as the demo user on its sign-in page, or sign in as demo with password try-bitdispatcher-demo. It is a dispatcher's console: everything on the console, the screens and the mobile terminal, but not the administration. The data is invented, around Roanoke, Virginia; simulated 911 calls arrive every 35 seconds; it goes back to the morning's incidents every night.

Build and run

Go 1.26 or newer, and Node 24 with corepack (pnpm) for the web interface.

git clone https://github.com/BioDream-LLC/bitdispatcher && cd bitdispatcher
make web build sim
./bin/bitdispatcher -demo      # https://localhost:8443; the first start prints the admin password once
./bin/bvsim                    # optional: a simulated BitVoice with 911 calls and radio traffic

-demo adds fictional stations and units around Roanoke, labelled as demo data. Then, in the browser:

  • Admin › Map: record the map for your area; the centre and radius are chosen on the map
  • Admin › Units, Stations, Call types & run cards: your agency
  • Admin › Integrations: BitVoice or another call-handling system; for the simulator, https://127.0.0.1:9444 with the token bv_simulated, then Read it to pin its certificate

The program is pure Go with no C libraries, built for Linux, macOS and Windows on Intel and Arm. make fips builds it with the Go Cryptographic Module under FIPS 140-3 certificate #5247, for agencies whose CJIS Systems Agency asks for validated cryptography.

Set it up yourself

Everything is configured on the admin screens, and nobody needs to come on site. Admin › Setup checklist shows what is left before the first live call, Admin › Go-live check tests the result (the ledger, a restore, a test call of every call type at every station, the connections), and Admin › Support builds a support bundle with no secrets and no caller data for whoever helps you. Support is remote: e-mail, phone or video. Your own staff and your phone, radio and paging vendors do anything that needs hands. bitdispatcher sends nothing anywhere by itself.
