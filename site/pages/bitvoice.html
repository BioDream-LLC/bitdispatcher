Call handling

With BitVoice, and without it

bitdispatcher takes the caller's location from any standards-compliant call-handling system. With BitVoice, BioDream's open-source phone system and 911 call handling, it uses every hook BitVoice offers a CAD. BitVoice is never required.

The standards at each boundary

FromWhatStandard
Any call-handling systemThe caller's number, class of service and locationALI spill over TCP or serial
Any NG911 systemThe caller's location, with its uncertaintyNENA i3 PIDF-LO
Any NG911 systemThe incident as the call-taker saw it, both waysEIDO (NENA-STA-024)
BitVoiceCalls ringing before answer, rebids, caller photos and video, texting the callerBitVoice's event stream and API
BitVoice's radio consoleEmergency buttons, acknowledgement both ways, unit positions, last heardBitVoice's radio webhook
The state's switchNCIC inquiries, logged with purpose and reasonThe state's message formats (a training simulator built in)

The full list of BitVoice's hooks and how each is used: docs/BITVOICE.md.
